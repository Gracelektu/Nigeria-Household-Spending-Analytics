# Nigeria Household Spending Analytics

An interactive data analytics dashboard built with Python and Streamlit to explore household income, spending, savings, and financial pressure patterns across Nigeria.

## Overview

The **Nigeria Household Spending Analytics** dashboard provides an interactive view of household financial patterns across different regions, income groups, and household sizes.

The project uses a synthetic dataset representing **1,000 Nigerian households** and was created to demonstrate how data analysis and visualization can be used to explore socioeconomic patterns and communicate findings through an accessible interactive interface.

## Key Features

* Interactive filtering by region, income group, and household size
* Household income, spending, and savings KPIs
* Analysis of spending across major categories
* Income versus household spending analysis
* Monthly spending trends
* Regional comparisons
* Income-group comparisons
* Financial-pressure analysis
* Automatically generated analytical insights
* Expandable household-level data table
* CSV data export

## Technologies Used

* **Python**
* **Streamlit** — interactive dashboard development
* **Pandas** — data manipulation and analysis
* **NumPy** — numerical operations and dataset generation
* **Plotly** — interactive data visualization

## Data

The dataset used in this project is **synthetic** and represents 1,000 Nigerian households. It was created for analytical and demonstration purposes and should not be interpreted as official Nigerian household expenditure statistics.

The synthetic data includes variables relating to:

* Household region
* Income
* Household size
* Spending
* Savings
* Spending categories
* Monthly financial patterns

## What the Project Explores

The dashboard allows users to investigate questions such as:

* How does household spending vary across regions?
* How does spending change across income groups?
* What proportion of income is directed toward different spending categories?
* How are income and expenditure related?
* Which household groups experience greater financial pressure?
* How do household financial patterns change over time?

## Running the Project Locally

Clone the repository:

```bash
git clone https://github.com/Gracelektu/Nigeria-Household-Spending-Analytics.git
```

Navigate into the project folder:

```bash
cd Nigeria-Household-Spending-Analytics
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```

The dashboard will then open in your browser.

## Project Purpose

This project was developed to strengthen practical skills in data analysis, visualization, and interactive application development while exploring household financial patterns within a Nigerian context.

It demonstrates the process of taking structured data, transforming it into meaningful metrics, identifying patterns, and presenting those findings through an interactive analytical application.
